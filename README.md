# Online Sales Analysis
Ovaj projekat predstavlja jednostavnu analizu online prodaje.
Omogucava upravljanje proizvodima, dodavanje proizvoda u korpu i izracunavanje ukupne vrednosti.

## Product

Klasa `Product` predstavlja jedan proizvod i cuva njegov naziv, cenu i kolicinu.Klasa sadrzi metode za prikaz informacija o proizvodu i azuriranje kolicine.

## ProductManager

Klasa `ProductManager` upravlja listom dostupnih proizvoda.

Klasa omogucava dodavanje i brisanje proizvoda, prikaz svih proizvoda i izracunavanje ukupne vrednosti inventara.


## Cart

Klasa `Cart` predstavlja korpu i cuva proizvode koji su u nju dodati.
Klasa omogucava dodavanje proizvoda u korpu, izracunavanje ukupne vrednosti korpe i prikaz njenog sadrzaja.


## Main

U `main.py` se kreiraju proizvodi, upravlja proizvodima preko `ProductManager` klase i nasumicno se biraju proizvodi koji se dodaju u korpu.

## Koriscenje

Program se pokrece izvrsavanjem fajla `main.py`.
